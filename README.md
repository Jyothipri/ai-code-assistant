# 🤖 AI Code Assistant

An AI-powered coding assistant developed for a college laboratory using Generative AI.

## Technologies Used

- Python
- Streamlit
- Hugging Face Inference API
- Generative AI
- GitHub

## Features

- Generate Code
- Explain Code
- Debug Code
- Convert Code
- Multiple Programming Languages

## Supported Languages

- Python
- C
- C++
- Java
- JavaScript

## How It Works

The user enters a programming problem in the Streamlit interface.

The application sends the request to a Generative AI model through the Hugging Face Inference API.

The generated response is displayed to the user.

## Project Architecture

User
↓
Streamlit Application
↓
Hugging Face Inference API
↓
Generative AI Model
↓
Generated Code / Explanation / Debugging

## Deployment

The application can be deployed using Streamlit Community Cloud with the GitHub repository.
